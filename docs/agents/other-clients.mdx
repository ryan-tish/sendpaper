Sendpaper is a remote MCP server using **Streamable HTTP** with no authentication:

```
https://sendmypaper.com/mcp
```

<AccordionGroup>
  <Accordion title="ChatGPT">Sendpaper is in ChatGPT's plugin directory: open **Plugins** in the sidebar, search for **Sendpaper** and install it. You can also add it yourself: in Plugins, select **+**, choose **Add custom MCP server** and paste the URL above. OpenAI notes that plan and workspace policies apply.</Accordion>
  <Accordion title="Cursor">
```json ~/.cursor/mcp.json
{ "mcpServers": { "sendpaper": { "url": "https://sendmypaper.com/mcp" } } }
```
  </Accordion>
  <Accordion title="VS Code">
```json .vscode/mcp.json
{ "servers": { "sendpaper": { "type": "http", "url": "https://sendmypaper.com/mcp" } } }
```
  </Accordion>
</AccordionGroup>
