---
title: "Send to several people"
description: "Mail the same postcard or letter to up to 25 people and pay once: holiday cards, announcements, the same notice to several parties."
---

One design, many recipients. Each person gets their own printed piece, mailed separately, with its own order page and tracking. You review and pay once for the whole group.

## What to tell your agent

Give it the design or wording once, then the list of people:

> Send this photo as a 6×9 postcard that says "Happy holidays from the Kims!" to my parents at 12 Oak St, Austin TX 78701, Jo Park at 8 Elm St, Dayton OH 45402, and Sam Rivera at 31 Lake Rd, Duluth MN 55802. From Alex Kim, 88 Pine Ave, Denver CO 80202.

Up to 25 recipients per group. For more, send several groups.

## What happens

- The agent calls `create_postcard` or `create_letter` with `recipients` (a list of addresses) instead of `to`.
- You get a **group page** listing every recipient, each with its own preview, and one total.
- It pays once with your approval ([agent payments](/guides/agent-payments)): `pay_order` with any order in the group pays for all of them. Or open the group's checkout link and pay there.
- A person reviews every piece before it's printed. If one is refused, only that one is refunded.

## From the web

On [sendmypaper.com/send](https://sendmypaper.com/send), choose what you're sending, then click **+ Add another recipient** under the first address. The total updates as you add people, and you pay once at the end.

## With the API

Pass `recipients` instead of `to` on `POST /postcards` or `POST /letters` ([API reference](/api/introduction)). The response is a batch:

```json
{
  "batch": {
    "id": "batch_…",
    "count": 3,
    "url": "https://sendmypaper.com/b/batch_…",
    "checkout_url": "https://sendmypaper.com/b/batch_…/pay",
    "price": { "amount_cents": 1197, "currency": "usd", "display": "$11.97" },
    "discount": null
  },
  "orders": [ { "id": "ord_…", "status": "awaiting_payment", "…": "…" } ]
}
```

Retrying with the same `Idempotency-Key` returns the same batch, so a network retry never sends twice.

<Note>The first-order discount, when a promotion is running, applies to every piece in your first group from a return address.</Note>
