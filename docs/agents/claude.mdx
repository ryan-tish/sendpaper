## Claude Code

```bash
claude mcp add --scope user --transport http sendpaper https://sendmypaper.com/mcp
```

## Claude Desktop and claude.ai

Open **Customize → Connectors**, click **+ Add**, choose **Add custom connector**, name it Sendpaper and paste:

```
https://sendmypaper.com/mcp
```

For authentication, choose **No sign in**. In a chat, switch Sendpaper on under **+ → Connectors**. Custom connectors are available on every Claude plan (the Free plan allows one); on Team and Enterprise plans an Owner adds them in Organization settings ([Anthropic's guide](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)).
