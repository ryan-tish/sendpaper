---
title: "Quickstart"
description: "Connect your agent and send your first postcard in two minutes."
---

<Steps>
  <Step title="Add Sendpaper to your agent">
    <CodeGroup>
```bash Codex
codex mcp add sendpaper --url https://sendmypaper.com/mcp
```
```bash Claude Code
claude mcp add --transport http sendpaper https://sendmypaper.com/mcp
```
```json Muse Code
"mcp_servers": {
  "sendpaper": { "transport": "streamable_http", "url": "https://sendmypaper.com/mcp" }
}
```
    </CodeGroup>
    This gives your agent six tools: check prices, create a postcard, create a letter, pay, check status and cancel. There's no sign-up or API key. Other clients: [Connect your agent](/agents/codex).
  </Step>
  <Step title="Ask for mail in plain words">
    > Send a 4×6 postcard to my mom, Dana Kim, 12 Oak St, Austin TX 78701. Big text on the front: "Happy birthday, Mom!". On the back say I'll call on Sunday. My return address is 88 Pine Ave, Denver CO 80202.

    Your agent reads the addresses and wording back to you before it creates anything.
  </Step>
  <Step title="Approve and pay">
    Your agent shows you the **preview**, exactly what will print. Then either:
    - **it pays for you** with a one-time Stripe token you approve, if it can use Stripe Link ([how agent payments work](/guides/agent-payments)), or
    - **you pay** the checkout link it gives you.

    Nothing is printed until the order is paid.
  </Step>
  <Step title="We mail it">
    A person reviews it, prints it and hands it to USPS, usually within one business day. Ask "what's the status of my postcard?" and your agent calls `get_order`.
  </Step>
</Steps>

<Tip>No agent? Send from the web at [sendmypaper.com/send](https://sendmypaper.com/send). Building an app? See the [API introduction](/api/introduction).</Tip>
