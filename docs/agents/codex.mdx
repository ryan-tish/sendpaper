## Install the plugin (recommended)

The plugin bundles the MCP server with a skill that teaches Codex the right flow (confirm addresses, show the preview, hand over the checkout link).

```bash
codex plugin marketplace add ryan-fern/sendpaper-plugin
```

Then open the plugin directory in Codex and install **Sendpaper**.

## Or add the MCP server directly

```bash
codex mcp add sendpaper --url https://sendpaper.onrender.com/mcp
```

Or in `~/.codex/config.toml`:

```toml
[mcp_servers.sendpaper]
url = "https://sendpaper.onrender.com/mcp"
```
